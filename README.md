Coach KPI Dashboard
Project for football coaches based on League of Ireland match data I watched and coded myself. This is a side project built to practice data analytics and football performance analysis. The app contains an interactive dashboard with KPIs, small-sided games (SSGs), and visual analysis.

What's included
Interactive pitch view, KPI library, SSG session designs, and charts.
Built with Vite + React + Recharts.
Deploys to GitHub Pages via the gh-pages package.
